# 과제 06: 순차 탐색, BST, AVL 트리의 성능 비교

아래 내용은 시드 1791077274의 실제 실행 결과를 바탕으로 작성하였다. 전체 출력은 `execution_result.txt`에 기록하였다.

## 1. 실제로 저장된 서로 다른 값의 수

0~1000의 정수를 100번 생성하여 세 자료구조에 같은 순서로 처리하였다. 중복 4개를 제외하고 배열, BST, AVL에 각각 같은 96개의 서로 다른 값이 저장되었다. 배열은 최초 발생 순서를 유지하며 정렬하지 않았다.

## 2. 생성 과정에서 발생한 비교 횟수

| 배열 | BST | AVL |
|---:|---:|---:|
| 4,782회 | 1,242회 | 1,052회 |

데이터 간 `==`, `<`가 실행될 때마다 각각 1회로 계산하였다. BST와 AVL은 같은 값을 만난 노드에서 1회, 다른 값을 만난 노드에서 2회 비교한다. 중복 확인도 포함하며 높이 계산, 균형 검사 및 회전은 제외한다.

## 3. 배열의 길이, BST의 높이, AVL의 높이

| 배열 길이 | BST 높이 | AVL 높이 |
|---:|---:|---:|
| 96 | 12 | 8 |

높이는 루트부터 가장 깊은 단말 노드까지의 노드 수로 계산하였다. 빈 트리는 0, 루트만 있는 트리는 1이다.

## 4. 탐색의 총 및 평균 비교 횟수

| 탐색 방법 | 총 비교 횟수 | 평균 비교 횟수 |
|---|---:|---:|
| 순차 탐색 | 4,563 | 91.26 |
| BST 탐색 | 821 | 16.42 |
| AVL 탐색 | 683 | 13.66 |

동일한 탐색 대상 50개를 사용하였으며 세 방법 모두 성공 5회, 실패 45회였다. 평균은 성공과 실패를 포함한 총 비교 횟수를 50으로 나눈 값이다.

## 5. BST와 AVL의 높이가 서로 다른 이유

BST는 입력 순서에 따라 구조가 결정되며 삽입 후 균형을 조정하지 않는다. 이번 입력에서는 일부 경로가 길어져 높이가 12가 되었다. AVL은 회전으로 각 노드의 좌우 서브트리 높이 차이를 1 이하로 유지하여 높이가 8이었다. 같은 데이터를 저장해도 노드 배치가 달라 높이에 차이가 생겼다.

## 6. 트리 높이가 탐색 비교 횟수에 미치는 영향

탐색은 루트에서 한 경로만 따라가므로 높이는 방문할 수 있는 노드 수의 상한에 영향을 준다. 이번 실험에서 높이가 낮은 AVL은 평균 13.66회로 BST의 16.42회보다 적게 비교하였다. 없는 값 667을 찾을 때에도 BST는 12개 노드를 방문하여 24회, AVL은 7개 노드를 방문하여 14회 비교하였다.

다만 전체 높이가 낮아도 특정 탐색 경로는 더 길 수 있다. 이번 50회 중 12회는 AVL의 비교 횟수가 BST보다 많았으므로 모든 탐색에서 AVL이 더 적게 비교한다고 볼 수는 없다.

## 7. 생성 비용과 탐색 비용 비교·분석

배열은 새 값을 넣을 때마다 기존 원소를 순차적으로 확인하여 생성 비교 횟수가 4,782회로 가장 많았다. 탐색 실패 시에는 96개 원소를 전부 확인한다. 이번 실험은 실패가 45회로 많아서 평균 탐색 비교 횟수도 91.26회로 배열 길이에 가까웠다.

BST와 AVL은 대소 관계에 따라 한쪽 서브트리로 이동하므로 배열보다 생성과 탐색의 비교 횟수가 적었다. AVL은 균형 유지로 경로를 짧게 만들어 BST보다 생성 비교는 190회, 탐색 비교는 138회 적었다.

그러나 AVL의 높이 갱신과 회전 비용은 측정에서 제외되므로 비교 횟수만으로 실제 실행 시간까지 더 짧다고 단정할 수 없다. 이번 결과는 한 번의 실험이며 입력 순서와 탐색 대상에 따라 수치는 달라질 수 있다.
